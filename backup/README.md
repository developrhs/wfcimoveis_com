## Segurança

Os arquivos de `legacy-site/` são ignorados pelo Git. Eles podem conter dados pessoais, dumps de banco, configurações, logs, chaves privadas e credenciais. Não fazer commit, push, upload público ou compartilhar essa pasta sem uma revisão de segurança e anonimização.

O backup é uma fotografia da hospedagem. Alterações posteriores no HostGator não aparecem automaticamente nesta cópia.
